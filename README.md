# Image Steganography Tool Using Java

## Project Overview
Image Steganography Tool is a Java-based desktop application that allows users to hide secret messages inside images and retrieve them later.

## Features
- Select an image from the computer.
- Encode secret messages into images.
- Decode hidden messages from encoded images.
- Password-based protection.
- Image preview.
- Input validation and error handling.
- Save encoded images in PNG format.
- Clear the application interface.

## Technologies Used
- Java
- Java Swing
- Java AWT
- ImageIO
- Least Significant Bit (LSB) Technique

## Project Files
- `Main.java` – Handles the graphical user interface.
- `Steganography.java` – Handles message encoding and decoding.
- `.gitignore` – Prevents compiled files from being uploaded.

## How to Run

1. Install JDK 21 or a compatible Java Development Kit.
2. Open the project folder in VS Code.
3. Open the terminal in the project folder.
4. Compile the files:

   `javac Steganography.java Main.java`

5. Run the application:

   `java Main`

## Output
The application allows users to hide messages inside PNG images and retrieve them using the correct password.
